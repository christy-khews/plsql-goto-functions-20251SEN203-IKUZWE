# Assignment Reflection & Learning Experience

## 1. Overview & Key Concepts Learned
In the context of this assignment, I learned key concepts of PL/SQL programming language, such as the usage of GOTO branching, creation of PL/SQL modules (Stored Functions), exception handling (NO_DATA_FOUND) and test case development.
New technical abilities acquired:

GOTO Statements: learned the implementation and implications of using GOTO branching and labels (<>), refactored several GOTO statements to IF-THEN-ELSIF statements.
PL/SQL Stored Functions: created several PL/SQL stored functions that return specific data types (NUMBER, VARCHAR2) and used positional or named notation to pass IN parameters.
Exception Handling: implemented EXCEPTION block to manage NO_DATA_FOUND exception and avoid run-time errors while testing.

## 2. Challenges Encountered & Resolutions
During the execution of the assignment, I encountered a few challenges, such as:
Substitution Variable Pop-up in Oracle Live SQL: while executing test script, a pop-up window appeared, asking to input a value for a substitution variable (probably, because of & NEGATIVE). Learned how to escape special characters.
Label Scope: discovered that GOTO cannot jump into a THEN clause or an ELSIF clause.

I have used an AI assistant while performing this assignment for:
Code Debugging: assistance while debugging Oracle Live SQL code.
Test Case Development: suggested test cases, including negative test cases (NULL, invalid parameters), implementation of test suite;
Repository Documentation: documentation of the repository (README.md, REFLECTION.md).
